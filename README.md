# 衣票墙（hangslip）

收衣贴号 → 工序推进 → 取衣核销关账 → 超期/丢失隔离互证。

- 前端 http://127.0.0.1:6200
- API http://127.0.0.1:11200

## 并票口径（合并事务世代）

全局只有一套口径，任何入口都听它：

- 合并码、衣物件键迁移、旧票退账（子票关「已并」退出在途）、事件、水位、
  待取墙在**同一个写事务**内落账；中途失败整体回滚，不存在「码已发、件未迁」。
- 合并码即该世代号（`ticket_merges.merge_code`），不是独立凭证；能否使用由
  **世代重放核对**裁决，不认任何单独的「成功」标记。
- 重放核对（`GET /api/并票/{group_id}/核对`、`POST /api/并票/扫码`）逐条检查：
  件键都在父票名下且来源和等于子票退账件数、子票关账并指向父票、水位增量等于
  子票张数、无散挂/孤儿/双挂。任一不闭合，合并码作废、总览不计成功。
- 差异收口用 `POST /api/并票/核对`（签账）：不闭合世代显式置作废、水位按票籍重算；
  作废后合并码/旧票暗码都不能放行取衣。
- 件键台账 `GET /api/并票/件键` 与总览的 `件键闭合 / 水位闭合` 同源读库。

本地开发：

```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\uvicorn app.main:app --host 127.0.0.1 --port 11200

cd ..\frontend
npm install
npm run dev
```
